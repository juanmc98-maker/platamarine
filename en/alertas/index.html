How it works

I save what you're looking for in my buyers' list. Every boat that comes into our listings I compare against that list and, if it fits, I write to you with the details before offering it anywhere else. If a boat doesn't quite fit but I think you might be interested anyway, I'll tell you just as honestly. And if you're in a hurry, it also helps to message me on WhatsApp: with what you're looking for I can also actively search among private sellers.

What this isn't

It isn't a mailing list or an automatic notification of new listings. The alert is kept for twelve months; if nothing that fits has come in by then, I'll write to you once to ask if you're still looking, and if you don't reply I'll delete it. You can ask me to delete it whenever you like by replying to any email.
